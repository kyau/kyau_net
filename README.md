## Stack

- Framework: [Aurora](https://github.com/kyaulabs/aurora) (`aurora/` git submodule), template engine with SRI-hashed, cache-busted asset injection
- Backend: PHP 8.5+ (Composer), flat PHP — no framework beyond Aurora
- Frontend: SCSS → Dart Sass (compressed) & vanilla JS ES modules → terser, self-hosted fonts, vendored three.js
- Tests: Pest 5 / PHPUnit 13
- Style: PHP CS Fixer, stylelint
- Commits: Conventional Commits, enforced by commitlint; secrets scanned by gitleaks
- Releases: SemVer tags, notes generated by git-cliff

## Development

### Requirements

- PHP 8.5+, Composer 2
- pnpm (frontend toolchain)
- `commitlint`, `gitleaks`, `git-cliff` available on `PATH`

### Install

```text
git clone --recurse-submodules git@github.com:kyau/kyau_net
composer install
pnpm install
```

### Frontend Build

SCSS sources live in `cdn/sass/`, JS sources in `cdn/js/`; both are compiled
into `cdn/css/` and `cdn/javascript/` (generated, committed — deployment has
no build step):

```text
pnpm run build       # css + js
pnpm run build:css   # cdn/sass/site.scss → cdn/css/site.min.css
pnpm run build:js    # cdn/js/*.js → cdn/javascript/*.min.js
pnpm run lint:scss   # stylelint over cdn/sass/
```

Never edit `cdn/css/*.min.css` or `cdn/javascript/*.min.js` directly.

Serve locally with the document root at `public/`:

```text
php -S localhost:8080 -t public
```

### Checks

```text
composer lint           # PHP syntax over backend/, public/, tests/ and index.php
composer format:check   # PHP CS Fixer, dry-run
composer test           # Pest test suite
composer coverage       # tests + Clover coverage at build/clover.xml
```

Changed-file coverage gate (90% minimum on changed PHP files):

```text
git diff --name-only origin/develop...HEAD -- '*.php' \
  | php .github/scripts/coverage-gate.php build/clover.xml --min=90
```

### Git Hooks

Hooks live in `.github/hooks` and are activated with:

```text
git config core.hooksPath .github/hooks
```

* `pre-commit`: gitleaks staged-secret scan
* `commit-msg`: commitlint message validation

## Testing

```text
composer test        # or: ./vendor/bin/pest
```

* `tests/Unit` — `Project` value object, `Portfolio` collection,
  `SectionRenderer` markup/escaping
* `tests/Feature` — renders `public/index.php` (and the root shim) through
  Aurora and asserts document structure, landmarks, anchors, SRI tags, the
  WCAG-critical parts of the SCSS source and scripts, and the committed
  build output

## Accessibility

* Semantic landmarks (`header` / `nav` / `main` / `footer`), one `h1`,
  section-scoped `h2`s wired via `aria-labelledby`
* Skip link as the first focusable element; visible `:focus-visible` outlines
* Rail nav state mirrored with `aria-current`; decorative art is
  `aria-hidden`; external links announce new tabs to screen readers
* `prefers-reduced-motion` disables reveals, deck navigation and all animation
* Fully usable with JavaScript disabled (reveals are `.js`-gated)

```text
├── backend/         # KYAU\Net — Project, Portfolio, SectionRenderer
├── brand/           # KYAU brand pack (boards, logos, icons, wordmarks)
├── cdn/
│   ├── sass/        # SCSS source (edit these)
│   ├── js/          # JS source (edit these)
│   ├── css/         # GENERATED — minified stylesheet
│   ├── javascript/  # GENERATED — minified scripts + vendored three.js
│   ├── fonts/       # self-hosted fonts
│   └── img/         # images incl. img/brand/ web brand assets
├── public/          # webroot: index.php (Aurora caller), favicon, cdn symlink
├── templates/       # Aurora template overlay (index.html)
├── tests/           # Pest: Unit + Feature
└── index.php        # front-controller shim (docroot = repo root, dev only)
```

## Deployment

Point the document root at `public/`. The CDN tree is served through the
`public/cdn → ../cdn` symlink, while Aurora resolves asset paths on disk
relative to the calling script — so SRI hashes and cache-busting keep working.
Nothing outside `public/` is web-accessible; no extra server hardening rules
are required.
